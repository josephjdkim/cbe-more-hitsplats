The main README shows these images. Save each one here as a PNG under its file name.

| File | What it shows |
|---|---|
| `without-plugin.png` | A crowded NPC, such as the Gemstone Crab, with the plugin off: only four hitsplats |
| `with-plugin.png` | The same scene with the default settings |
| `columns-1.png` | Columns per side set to 1 |
| `columns-4.png` | Columns per side set to 4 |
| `large-total.png` | Display total damage on, in a crowd |
| `your-missing-hits.png` | Your estimated hit under the game's left hitsplat, at the Gemstone Crab |
| `settings.png` | The plugin's settings panel |

Tips:

- Use the same camera zoom for every shot.
- Crop out the chat box and player names.
