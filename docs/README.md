# Screenshots

The main README shows these images, all taken at the Gemstone Crab. To update one, replace its file and keep the name.

| File | What it shows |
|---|---|
| `columns-2.png` | Columns per side set to 2, the default |
| `columns-3.png` | Columns per side set to 3 |
| `total-marked.png` | Display total damage on, with Mark unconfirmed totals on |
| `total-unmarked.png` | Display total damage on, with Mark unconfirmed totals off |
| `missing-hits-off.png` | A crowded tick with none of your hits |
| `missing-hits-on.png` | A crowded tick with your estimated hit |

Tips:

- Use the same camera zoom for every shot.
- Crop out the chat box and player names.
